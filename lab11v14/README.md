### Тема

NotificationService: шаблонні кроки й реалізації. Патерн Template Method.

### Варіант

14. `NotificationService → EmailNotification / SMSNotification / PushNotification`

**Абстрактний клас: `NotificationService`**
* Шаблонний метод: `Notify()`.
* Методи обробки: `ValidateRecipient()`, `FormatMessage()`, `Send()`, `LogDelivery()`.
* Властивості: `Recipient`, `Message`, `IsSent`.
* Абстрактні методи: `ValidateRecipient()`, `Send()`.
* Віртуальні методи: `FormatMessage()`, `LogDelivery()`.

**Похідні класи:**
* `EmailNotification` — перевіряє адресу електронної пошти, форматує повідомлення з темою та імітує відправлення email.
* `SMSNotification` — перевіряє номер телефону та імітує відправлення SMS.
* `PushNotification` — перевіряє токен пристрою, імітує відправлення push-сповіщення та перевизначає логування результату.

### Хід роботи

1. Створено консольний проєкт `lab11v14`.
2. Реалізовано абстрактний клас `NotificationService` із шаблонним методом `Notify()`.
3. Визначено абстрактні методи `ValidateRecipient()` і `Send()`, а також віртуальні методи `FormatMessage()` і `LogDelivery()`.
4. Створено похідні класи `EmailNotification`, `SMSNotification` і `PushNotification`.
5. У методі `Main()` створено колекцію `List<NotificationService>` та додано до неї об'єкти всіх трьох похідних класів.
6. Викликано метод `Notify()` для кожного об'єкта через посилання базового типу.
7. Продемонстровано послідовне виконання перевірки отримувача, форматування повідомлення, відправлення та логування результату.
8. Для `PushNotification` перевизначено метод `LogDelivery()`, який додатково виводить стан відправлення.
